# Voice Commands

Offline voice commands via Vosk with a fixed vocabulary. Same fair-play rule:
**one spoken command → one game action.**

## Guidelines for choosing words
- Short and distinct: one or two syllables, unlike each other
  ("mount" and "map" are close; "bags" and "back" are close)
- Avoid words you say often on Discord or voice chat
- Avoid words that sound like common filler ("uh", "okay")

## App-control commands (do not send game keys)
| Spoken word | App action |
|---|---|
| (suggested) "gestures off" | Pause gesture input |
| (suggested) "gestures on" | Resume gesture input |
